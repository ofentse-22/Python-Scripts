A collection of Python scripts and mini-projects covering fundamental concepts, logic building, and terminal-based applications.
# Python Fundamentals Practical Code

This folder contains runnable Python examples based on the practical parts of
`Python_Fundamentals.docx`.

Each numbered file focuses on one topic from the notes. Students can run the
files one at a time and then edit the values to see what changes.

Suggested order:

1. `01_variables_and_assignment.py`
2. `02_strings.py`
3. `03_numbers_and_operators.py`
4. `04_booleans_and_comparisons.py`
5. `05_collections.py`
6. `06_control_flow_decisions.py`
7. `07_loops_and_iteration.py`
8. `08_file_io.py`
9. `09_csv_files.py`
10. `10_command_line_arguments.py`
11. `11_functions.py`
12. `12_error_handling.py`
13. `13_modules_and_imports.py`

The file `student_math_tools.py` is a small helper module used by
`13_modules_and_imports.py`.

Example commands from the repo root:

```powershell
py "Python Fundamentals notes\01_variables_and_assignment.py"
py "Python Fundamentals notes\10_command_line_arguments.py" 5 10
```
